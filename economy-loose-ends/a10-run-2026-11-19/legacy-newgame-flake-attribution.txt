-----------------------------------------------------------------------------
4. WHY IT IS NOT RANDOM, AND WHY IT IS NEW
-----------------------------------------------------------------------------

Default run order is alphabetical, and `tests/Command/Economy*` sorts before
`tests/Controller/Api/Legacy*`. So the polluter always runs first in a full run
and this failure is DETERMINISTIC from now on, not a coin flip — unlike #4 and
#5, which genuinely come and go. It is new because both polluting files landed
today with A7 (`LeagueTvDealResyncTest` and `EconomyAuthoredSizeDriftTest` are
named in A7's own last-sync entry), which is why A7's 3,294-test run reported
three failures and not four.

-----------------------------------------------------------------------------
5. WHERE THE FIX BELONGS
-----------------------------------------------------------------------------

In the POLLUTERS, not in `LegacyNewGameFlowTest`. The reader is asserting a real
invariant — that the economy block ships switched off — and its docblock names
exactly the mistake it is there to catch: "shipping a non-zero inflation rate or
an authored turnover table by accident, which would change what every existing
save derives without anyone choosing it." That is worth keeping.

`EconomyAuthoredSizeDriftTest` and `EconomyTvCountryScalingGuardTest` need the
turnover row for their own run and should put it back, or stop persisting it.
NOT FIXED HERE: this report's task was told not to change code for any of this.
